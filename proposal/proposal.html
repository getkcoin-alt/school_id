01Project Overview

The platform digitises the full school ID card process, from collecting student data and photos to printing and delivering finished cards. Schools no longer need to collect paper forms and photos manually. Each student receives a personal link, fills in their own details and takes a fresh photo, and the school approves the record before it goes to print.

03Solution Workflow

1 · Collect
The School Admin imports the student list (CSV/XLSX) and sends personal invitation links by email.
2 · Submit
Students verify their link, fill in the school's configured fields and capture a live photo.
3 · Review
The School Admin reviews each submission, corrects details or requests changes, then approves it.
4 · Print & Deliver
Approved records become print batches with card PDF proofs. Agents track progress from printing to delivery.

04Scope of Work

One fixed price covers all of the following:

A · UI / UX Design
  • Final design pass on all existing screens
  • Responsive behaviour for desktop, tablet and mobile
  • ID card front/back and lanyard template layouts
  • Email invitation and notification templates
  • ID Card Studio branding applied consistently
B · Frontend Development
  • All 5 role panels connected to live data
  • Student, staff, class, section, session and promotion modules
  • Student self-submission form with camera capture
  • School review, correction and approval screens
  • Print batches, card PDF proofs and CSV exports
  • Form validation, empty states and user guidance
C · Backend Development
  • Secure login with role-based access control
  • REST APIs for every module in the frontend
  • Database for schools, students, staff and batches
  • Signed, expiring invitation links with email code check
  • Photo and PDF upload storage for each school
  • Audit trail of approvals and print status changes
D · Integration & Launch
  • Frontend and backend integrated end to end
  • Transactional email service for invitations and codes
  • Bulk CSV/XLSX import with duplicate checks
  • Deployment to the client's server or cloud, with SSL
  • Functional testing across all roles before go-live
  • Handover walkthrough and admin training session
