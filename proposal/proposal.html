01Role Panels

PanelAccess
AdminFull control of schools, agents and platform settings. Can view the activity logs of every agent and school.
SchoolManages its own student data: uploads it by Excel or collects it through onboarding links and bulk emails, and reviews and approves ID card data.
Agent: PremiumWorks on assigned schools with download access. Can view its own logs and the logs of its schools.
Agent: RegularWorks on assigned schools without download access. Can view its own logs and the logs of its schools.

02Student Onboarding Flows

Two ways to onboard student data. Both end in the same school review, approval and print process.

ExistingFlow 1 · Excel Upload
1 · Prepare
Download the Excel template and fill in the student data.
2 · Upload
Import the Excel/CSV file. Rows are validated and duplicates skipped.
3 · Photos
Add student photos individually or in bulk.
4 · Review & Print
The school approves the data, which then goes to print.
NewFlow 2 · Link Sharing
1 · Share
Copy a student's link, or bulk-email it to selected students with an email ID.
2 · Submit
The student opens the link and fills in their own details and photo.
3 · Review
The school checks the submission, corrects it if needed and approves it.
4 · Print
Approved data goes through the existing print and delivery process.

03Scope of Work

The fixed price covers all features discussed and agreed, as listed below.

A · Modern Design & User Guide
  • Modern, user-friendly redesign of all screens
  • Responsive on desktop, tablet and mobile
  • Built-in user guide explaining each panel and workflow
  • Clear hints, validation messages and empty states
B · Panels & Permissions
  • Three panels: Admin, School and Agent
  • Premium agents can download; Regular agents cannot
  • Staff panel removed
  • Role-based access control on every page and action
C · New: Student Onboarding Link
  • Personal ID card data link for each student
  • Link sharing by copying the link only
  • Bulk email with the link to selected students that have an email ID
  • Student submissions flow into school review and approval
D · New: User Activity Logs
  • Record of user actions on the platform
  • Admin can see all logs of agents and schools
  • Agents can see their own logs and their schools' logs
  • Filter logs by user, school and date
E · Existing Features (Retained)
  • All other features of the earlier ID Studio project, as delivered, including Excel student data upload
  • Including schools, agents, students, classes, sessions, photos, card designs, print batches and delivery tracking
F · Deployment
  • Setup of the client's own Linux server to run the software
  • Production deployment of frontend, backend and database
  • Final testing on the live server, then handover

04Complimentary: Portfolio Website Free

  • Up to 5 pages: Home, About, Products & Services, Gallery, Contact
